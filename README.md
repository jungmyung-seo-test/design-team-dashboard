# design-team-dashboard

무신사 Product Design 조직(디자인실) 역할·업무량 보드.

공개 URL — `https://jungmyung-seo-test.github.io/design-team-dashboard/`

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 비밀번호로 잠긴 보드. 페이지 전체가 AES-256-GCM으로 암호화돼 있다 |
| `.nojekyll` | GitHub Pages의 Jekyll 빌드 단계를 건너뛴다 |

GitHub Pages에는 인증 기능이 없다(접근 제어되는 Private Pages는 Enterprise Cloud 조직 전용).
그래서 **파일 자체를 암호화**해 올린다 — 서버에 올라간 것은 암호문이라 소스를 봐도 내용이 나오지 않고,
브라우저에서 비밀번호로 푼다.

## 비밀번호

- 팀에 공유된 비밀번호 하나로 모두가 같은 URL을 연다
- 한 번 열면 **같은 탭에서는 새로고침해도 다시 묻지 않는다**(탭을 닫으면 초기화)
- **비밀번호는 이 리포에 적지 않는다.** 링크와 다른 경로로 공유한다
- 바꾸려면 새 비밀번호로 다시 잠근 `index.html` 로 덮어쓴다.
  단, **이전 커밋의 파일은 옛 비밀번호로 계속 열린다** — 유출 시에는 리포를 삭제하고 다시 만든다

## 갱신

보드는 Jira를 실시간으로 부르지 않는다. **파일을 통째로 바꾸는 것이 곧 갱신**이다.

1. Claude 프로젝트 "⭐️ Product Design 업무 대시보드"에서 `데이터 갱신` 실행
2. 나온 잠금본 `index.html` 로 이 파일을 덮어쓰고 커밋
3. 1~2분 뒤 GitHub Pages가 자동 재배포. **URL은 그대로다**

화면 상단 `데이터 갱신 …` 이 이 파일이 담고 있는 Jira 스냅샷 시각이다.
